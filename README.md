# Sky Drift

A one-button drifting game for the browser. Steer a car along an endless, twisting road floating in the sky, and don't fall off.

## Play

Open `index.html` in any browser. Nothing to install.

- **Hold** the mouse, your finger, or **Space** to drift right ↗
- **Let go** to drift left ↖
- **P / Esc** pauses

## Features

- 3D chase camera with an endless, randomly generated track
- Road sections that change colour and pattern as you go
- Rolling bumps, jump ramps over gaps, and quick jogs
- Score for distance, drift bonuses and airtime
- Coins and a garage of 8 unlockable cars
- Power-ups: shield (respawn with countdown), slow-mo, coin magnet, double score
- Sound effects and music generated in code, with a saved high score

Everything lives in a single `index.html` file: plain HTML, CSS and JavaScript with no libraries.
